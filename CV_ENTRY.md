# CV Project Entry - Undergraduate Transfer Management System (UTMS)

Here are three different options for including this project in your CV, depending on the available space and desired emphasis.

## Option 1: Standard Bullet Points (Balanced)
*Best for highlighting both technical skills and project scope.*

**Undergraduate Transfer Management System (UTMS)** | *Full Stack Developer*
*   Designed and developed a comprehensive web application to automate student transfer processes at IZTECH, reducing manual paperwork.
*   Built a robust backend using **Java (Spring Boot)** with **Spring Security (JWT)** for role-based authentication and authorization across 5 different user roles.
*   Implemented complex business logic for automated application scoring and evaluation using **JPA** and **PostgreSQL**.
*   Created a responsive, modern frontend with **React** and **Tailwind CSS**, featuring custom dashboards for students and administrative staff.
*   Integrated **OpenPDF** and **Apache POI** to generate automated PDF and Excel reports for official use.
*   Containerized the entire application stack using **Docker** and **Docker Compose** to streamline deployment and development workflows.

## Technical Summary (For Interviews)
*   **Architecture:** Monolithic architecture with a clear separation of concerns (Service Layer pattern).
*   **Database:** Relational database design with PostgreSQL for production and H2 for testing.
*   **Security:** Stateless authentication using JSON Web Tokens (JWT) and BCrypt password hashing.
*   **Testing:** Unit and integration testing with JUnit and Mockito (implied standard practice).
