TEST STUDENTS (Generated by init_data.py)
================================================================================

50 test student accounts are created using the init_data.py script.
All test students follow the naming convention:
  student[number]_[dept]_[status]

Examples:
  - student01_cse_new
  - student02_mech_evaluated
  - student03_arch_approved

Password for all test students: Student123!

Departments:
  - cse  = Computer Engineering
  - mech = Mechanical Engineering
  - arch = Architecture

Statuses:
  - new       = Application submitted, at OIDB
  - forwarded = Forwarded to Dean's Office
  - evaluated = Evaluated by YGK
  - approved  = Final approval by Dean
  - rejected  = Not approved

To regenerate test data:
  1. Restart the backend (clears in-memory H2 database)
  2. Run: python3 tools/init_data.py

NOTES
================================================================================

- Default users are seeded via data.sql on backend startup
- In development mode: In-memory H2 database resets on restart
- In Docker/production mode: PostgreSQL database with persistent storage
- Use tools/init_data.py to quickly populate the system with 50 test students
- Password validation requires: uppercase, lowercase, numbers, special chars
- JWT tokens expire after 30 minutes (SEC-06)
